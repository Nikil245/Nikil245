## 📌 Featured Projects

### ⏰ LockIn Clock
A motivational flip-clock web app built using React, Tailwind CSS, Framer Motion, and LocalStorage.

**Features:**
- Retro flip clock UI  
- Motivational quotes by category  
- Pomodoro timer  
- Lock-in mode  
- Fullscreen focus mode  
- Persistent settings using LocalStorage  

🔗 Live Demo: https://lockin-clock.onrender.com  
📂 Repository: https://github.com/Nikil245/lockin-clock

---

### 🥁 Interactive Drum Kit Website
Developed a web-based drum kit using HTML, CSS, and JavaScript.

**Features:**
- Plays drum sounds using keyboard key presses  
- Interactive button-based drum controls  
- JavaScript keyboard event handling  
- Simple and responsive web interface  

🔗 Live Demo: https://drum-kit-2.onrender.com  
📂 Repository: https://github.com/Nikil245/Drum-kit

---

### 🤖 Multi-Agent Workflow Orchestration System
A research-based academic project focused on automating institutional workflows using multiple specialized agents.

**Main idea:**
- Student, Faculty, Attendance, Fees, Scholarship, Exam, Library, Placement, Notification, Orchestrator, and Event Attendance agents  
- Shared institutional context store  
- Rule-based workflows with LLM-powered orchestration  
- Designed for Indian educational institutions
